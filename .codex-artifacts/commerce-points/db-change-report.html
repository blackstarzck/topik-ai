2.2 서버측 잔액 계산 (금전성 핵심) 서버 이관

admin_create_manual_point_adjustment:
  • 사용자별 pg_advisory_xact_lock(hashtext('commerce_point_ledger_user:'||user_id))로 잔액 계산 직렬화(동시성)
  • 최신 ledger를 for update 잠금(없으면 0 기준) → v_next_balance = 최신 available_balance + p_amount 서버 계산
  • v_next_balance < 0 시 예외 + 테이블 CHECK (balance_after ≥ 0 and available_balance_after ≥ 0) 이중 가드
  • 클라이언트가 보낸 잔액 신뢰 안 함(supabase 경로에서 클라 getLatestUserBalance 계산 제거)
검증: 시드 8 원장 사용자 전원 잔액 음수 없음, 비음수 CHECK 제약 존재.
