2.3 신고 조치 의미 버그 정합화 (핵심) FIXED

admin_resolve_community_report(p_report_id, p_action, p_reason) — 단일 트랜잭션:
  • hide_post → 대상 community_posts.status='hidden' 실제 적용
  • suspend_user → 의도만 기록(payload user_suspend_integration=intent_only_v13_admin_set_user_status_pending) — 실제 사용자 정지는 v13 admin_set_user_status 종속(미연동·후속)
  • dismiss → 종결만
  • 항상 process_status='resolved' + resolution_action + resolved_by/at + 감사(action·affected_post/user)
검증: 시드 RP-003(hide_post resolved)의 대상 게시글 POST-003 = hidden 확인 → 버그 실수정.
